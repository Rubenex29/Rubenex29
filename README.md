## Featured project — RAG Against the Machine

**A local assistant for exploring source code and technical documentation.**

[RAG Against the Machine](https://github.com/Rubenex29/RAG) indexes the vLLM
codebase, combines keyword and semantic search, and uses a small local language
model to answer questions from retrieved context.

- **Hybrid retrieval:** BM25 + BGE embeddings + FAISS, combined with weighted RRF.
- **Source traceability:** retrieved passages include file paths and character offsets.
- **Local execution:** CPU inference with Qwen3-0.6B, persisted indexes and query caching.
- **Two interfaces:** command-line workflows and a FastAPI service.
- **Engineering decisions:** AST-aware Python chunks, recursive text splitting,
  documented retrieval evaluation and explicit trade-offs.

**Stack:** Python · FastAPI · FAISS · Sentence Transformers · BM25 · Qwen
